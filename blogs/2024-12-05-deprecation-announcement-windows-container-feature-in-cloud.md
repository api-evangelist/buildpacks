Deprecation of Support for Windows Containers Effective immediately, we are announcing the deprecation of the Windows Container feature in Cloud Native Buildpacks. This feature will no longer be supported and will be removed from future lifecycle versions starting in 2025 . This change does not impact Windows distributions of the Pack CLI , which will continue to be supported.
